# 亚马逊爆品选品系统（Pro 版）

基于 **Bella 日销3500单爆品方法论** 构建的 AI 选品决策工具，无需服务器，直接在浏览器中运行。

## 方法论来源

本工具严格遵循以下实战方法论构建：
- **第二课-亚马逊爆品体系化运营高阶.pptx** — 核心选品逻辑与框架
- **Bella厨房喷火器市调模板.xlsx** — 竞品拆解、用户画像、关键词分析模板
- **直播内容梳理.docx** — 方法论总结与实战案例

## 核心功能

### 七步科学选品流程

| 步骤 | 内容 | 方法论依据 |
|------|------|-----------|
| Step 1 | **Google Trends 趋势分析** | 识别真实趋势 vs 伪风口，判断季节性 |
| Step 2 | **市场概览 + ABA品牌分析 + 商机探测器** | 搜索量、CPC、细分市场增长分析 |
| Step 3 | **竞品深度拆解** | 垄断度分析（Top3<50%可进入）、产品属性矩阵 |
| Step 4 | **用户画像 + 需求金字塔** | WHO/WHAT/HOW/WHERE + 基础(65%)/期望(35%)/社交(5%) |
| Step 5 | **差异化机会 + 关键词供需比** | 供需比<0.4为蓝海词，数据→空白→机会 |
| Step 6 | **财务测算（全成本核算）** | 显性成本 + 隐性成本（广告/退货/仓储） |
| Step 7 | **Go / No-Go 最终决策** | 六维评分矩阵 + 行动计划 |

### 数据上传功能（弥补亚马逊无公开API的问题）

支持上传截图或文件，AI 自动识别提取数据：

| 类型 | 支持格式 |
|------|---------|
| Google Trends 截图 | PNG / JPG |
| 商机探测器截图 | PNG / JPG |
| ABA品牌分析截图 | PNG / JPG |
| 竞品 Listing 截图 | PNG / JPG |
| 评论数据截图 | PNG / JPG |
| BSR 排名截图 | PNG / JPG |
| 市调模板 Excel | .xlsx / .csv |

上传后，AI 会自动从图片/文件中提取关键数据（搜索量、趋势数值、竞品参数等），并在后续分析中优先使用真实数据而非估算值。

## 快速开始

### 方法一：本地打开

```
双击 index.html 在浏览器中打开
```

### 方法二：GitHub Pages 部署（推荐）

1. Fork 本仓库到你的 GitHub 账号
2. Settings → Pages → Source: `main` / `root`
3. 保存后访问 `https://你的用户名.github.io/仓库名`

## 使用步骤

1. 首次使用，在首页填入 [Anthropic API Key](https://console.anthropic.com/)
2. 输入目标关键词（如 `crossbody bags for women`）
3. 可选：填入已知竞品 ASIN
4. 选择目标市场（美国/英国/德国等）
5. 点击"开始七步选品分析"
6. 在任意步骤点击"📎 上传数据"可上传真实亚马逊数据截图

## 核心方法论要点（Bella）

- **选对产品 > 努力运营** — 错误的产品让顶尖运营也事倍功半
- **垄断度判断** — Top3品牌份额合计 < 50% 才是可进入市场
- **供需比分析** — 关键词竞争数/搜索量 < 0.4 为蓝海机会
- **伪风口识别** — 区分事件驱动短期暴增 vs 长期稳定趋势
- **全成本核算** — 显性成本 + 广告+退货+仓储等隐性成本
- **季节性布局** — 旺季提前 1-2 个月完成产品开发和关键词卡位
